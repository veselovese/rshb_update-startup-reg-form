## Переменные среды

### Базовые пераметры сервера
| Переменная          | Значение по-умолчанию   | Описание                                               |
|---------------------|-------------------------|--------------------------------------------------------|
| SERVER_PORT         | `8080`                  | Порт сервиса.                                          |
| EXTERNAL_URL        | `http://localhost:8080` | Внешний адрес сервиса.                                 |
| SERVER_SESSION_TTL  | `60d`                   | Время жизни сессии.                                    |
| ACTUATOR_PORT       | `8080`                  | Порт сбора диагностических данных о состоянии сервиса. |
| MAX_ATTACHMENT_SIZE | `20971520`              | Максимальный размер загружаемого файла (байт).         |
| LOG_DIR             | `logs`                  | Директория логов.                                      |

### Дополнительные параметры сервера
| Переменная      | Значение по-умолчанию | Описание          |
|-----------------|-----------------------|-------------------|
| SWAGGER_ENABLED | `false`               | Включить Swagger. |

### Параметры сбора статистики

|------------------------------------------|-----------------------|---------------------------------------------------------------------------|
| STATS_COLLECTION_ENABLED                 | `true`                | Включить механизм сбора данных статистики.                                |

| STATS_AGROBIT_TOURISM_COLLECTION_ENABLED | `true`                | Включить сбор данных статистики о туризме Агробит.                        |
